# 中文文字转音乐

一个计划运行在浏览器中的“二维音序器 + 实时合成器”：中文词语按照稳定、可解释的固定规则转换成音符，并组成一首有明确起止的短曲。

## 当前已确认的产品方向

- 输入粒度：词语与句子构成乐句，而不是简单的一字一音。
- 旋律原则：音乐性优先；普通话声调提供上升、下降等软约束，最终音符吸附到选定音阶。
- 词语身份：规范词语经过带版本号的 SHA-256 映射，生成稳定的起始音、节奏、音色、力度与装饰参数。
- 简繁处理：界面保留原文；计算音乐身份时统一为简体规范形式，因此“春风”和“春風”共享音乐身份。
- 曲目结构：按全文顺序生成完整曲目，不做固定循环。
- 第一版长度：10～300 个汉字，面向诗歌、短文和文案。
- 用户控制：提供调性、速度、整体音色和情绪倾向等基础调节，不做逐音符编辑。
- 情绪推断：使用本地规则、标点、句长和小型情绪词典生成默认情绪，用户可以覆盖。
- 运行方式：核心映射、情绪规则和 Web Audio 合成都在浏览器本地完成，不调用 AI API。
- 主界面布局：采用方案 B，以中央二维音序器轨道为主体，右侧集中放置参数控制。

## 当前算法轮廓

```text
原始文本
→ Unicode 与简繁规范化
→ 固定版本中文分词
→ 固定版本拼音与声调解析
→ SHA-256 词语身份
→ 多维音乐参数生成
→ 声调约束旋律方向
→ 标点与句子组织乐段
→ Web Audio 实时播放
```
